## 商品表和商品明细表有什么区别

| 表 | 一行代表什么 | 主要用途 |
| --- | --- | --- |
| olist_products_dataset.csv | 一个 product_id 对应的商品属性记录 | 品类、重量、尺寸及展示信息 |
| olist_order_items_dataset.csv | 一笔订单中的一条商品明细 | 成交价格、运费、卖家和销售记录 |
| product_category_name_translation.csv | 一个葡萄牙语品类对应的英文映射 | 为品类分析补充英文名称 |

商品表没有成交价格字段。商品成交金额仍来自订单商品明细的 price；同一商品可以在不同订单或同一订单多条明细中出现。商品主数据行数不等于销售件数或订单数。

## 商品表字段

字段含义参照原始目录中的中文数据字典。

| 字段 | 含义 |
| --- | --- |
| product_id | 商品 ID，当前表的主键 |
| product_category_name | 葡萄牙语品类名 |
| product_name_lenght | 商品名称字符数，不是商品名称文本 |
| product_description_lenght | 商品描述字符数，不是描述文本 |
| product_photos_qty | 商品展示图片数量 |
| product_weight_g | 记录的商品重量，单位克 |
| product_length_cm | 记录的长度，单位厘米 |
| product_height_cm | 记录的高度，单位厘米 |
| product_width_cm | 记录的宽度，单位厘米 |

两个 lenght 是原始列名的拼写，读取时保持一致。翻译表只翻译品类名，不提供每个商品名称的英文翻译。

## 为什么关联使用 many_to_one

左侧商品表里，同一品类可能对应多个商品，所以 product_category_name 可以重复。右侧翻译表里，每个葡萄牙语品类最多一行。

因此左侧多行可以匹配右侧一行，使用 validate='many_to_one'。它验证右侧映射键唯一，防止翻译表重复键使商品行数被放大；不负责去重。

关联仍以商品表为左表，保留全部商品。翻译表映射键先检查非空且唯一，英文值检查非空，避免关联后不清楚缺失来自哪一侧。
