## 指标字典

| 指标 | 计算与粒度 | 空值及限制 |
| --- | --- | --- |
| 下单订单数、交付率 | 按 `order_id` 一单一次；交付率为已交付数 ÷ 全部下单数 | 下单日期确定月份，订单状态反映数据记录中的最终状态 |
| 商品成交额、客单价 | 已交付订单明细 `price_cents` 求和 ÷ 100；客单价再除以有金额明细的已交付订单数 | 商品成交额不含运费，不能当作收入、利润或支付额 |
| 运费及其比例 | 已交付商品明细 `freight_cents` 求和 ÷ 100；再除以商品成交额得运费占商品金额比 | 0 运费可以是合法记录，分母为零时比率为空 |
| 成交额环比和拆解 | 本月减上月，差额 ÷ 上月为环比；用上月客单价乘订单量差算订单量贡献 | 只比较相邻完整月，金额贡献按已交付且有商品明细的订单口径 |
| 延迟率 | 晚于预计日期的已交付订单 ÷ 可判断延迟的已交付订单；按自然日 | 缺失或不可信日期留未知。运输按经过时间，两种天数口径不同 |
| 履约 P50/P90 | 各阶段独立过滤有效时长，算中位数和第 90 百分位，单位天 | 有效样本数可能不同，各州比率和分位数按该州订单重算 |
| 最新评分及低评分率 | 每单唯一的最新有效评分；1、2 星订单 ÷ 有有效评分的订单 | 无评分不计分母；延迟专题还需要可判断延迟 |
| 卖家基线和跟进 | 只用单卖家已交付订单，延迟和低评各用相应分母；各至少 50 笔且两个率均严格高于基线才入选 | 基线是订单加权的总体率；聚类不是规则名单，多卖家订单另行核查 |
| RFM | 客户键 `customer_unique_id`；R 距基准日、F 订单数、M 商品金额 | 该客户任一单缺金额则 M 未知；先分 F，再用组内 P75 |
| 月度后续购买占比 | 该下单月非首单的已交付订单数 ÷ 当月已交付订单数 | 窗口前没有完全可见的历史，首单只指窗口内首单 |
| N 天复购率 | 同一首购月在 N 天内有第二单的客户 ÷ 观察期完整的首购客户 | 本项目要求该月所有人都成熟才展示；未成熟留空，成熟且分子为零显示 0% |

## 三条建议及验证设计

下面是从结果出发的建议稿。动作、对照和验证期都是下一阶段计划。

| 发现 | 建议做什么 | 怎么知道动作有效 |
| --- | --- | --- |
| 2017 年 11 月商品成交额增加 339,517.72 BRL，订单量贡献 +406,928.13，客单价贡献 −67,410.41。品类增量首位为 `bed_bath_table`，客户州增量首位为 SP | 先复核高增量品类和地区是否有备货或运力压力。补采活动、库存和仓配数据后，再决定是否试点调配 | 从可比品类与州中挑一部分先试点，记录试点前后 4 周已交付订单数、客单价和缺货或延迟指标，与同期对照比较。订单量变多还需检查客单价与交付是否恶化 |
| 按时或提前组低评率 9.25%，延迟 8–14 天组为 80.15%。统一州权重后，延迟与按时组仍相差 50.46 个百分点 | 在延迟常见线路排查交承运商和运输两个阶段，优先试点异常件升级处理 | 挑相近线路或卖家分批实施，观察至少 4 周下单并等订单完成交付及评分。比较超过 7 天延迟率、评价覆盖率和低评分率。各率分别报告分子、分母和区间 |
| 408 位卖家参与聚类，规则入选 102 位。只跟进簇 1 会漏掉 30 位其他簇的入选者 | 按低评和延迟笔数排序，从规则名单中抽取订单复核原因。聚类用于分配排查方法 | 用分批名单或随机顺序安排跟进，记录动作和基准。之后比较固定随访窗口内的延迟率、低评率和覆盖率，并把多卖家订单单列做敏感性检查 |

客户模块可作为补充建议。先从最近 90 天内有购买、且单次购买金额达组内 P75 的客户中定义一组再营销试点，然后用随机留组比较完整的 30 天复购率。需要新增触达记录才能评估。RFM 与 Cohort 描述历史行为，无法直接衡量触达效果。

## 作品目录、简历和五分钟讲法

在交付前整理这些材料。运行自己的报表后再用实际截图替换占位说明。

- `README.md` 写项目问题、三条主发现、复现顺序和产物入口。复现链为原始 CSV → 清洗/Parquet → MySQL 入库和专题 SQL → Python 回归、聚类和 BI 数据准备 → Power BI。Q23–Q24 与 Q29–Q31 由 Python 运行；其余 30 个 Q 编号是 SQL。
- `powerbi/` 留自己的 PBIX、选定状态的截图和一张模型图。跟审核人分享时说明路径刷新方法，截图只展示必要字段。原始数据、数据库密码、本机连接配置和自动生成的数据目录不放进公开仓库。
- 研究记录留本表、指标字典、测试和结果引用。Q17 可追到延迟分母，Q14 可追到空值口径，Q27 可追到名单规则。
