## 字段与粒度

字段含义依据原始目录中的数据含义说明。

| 字段 | 含义 |
| --- | --- |
| seller_id | 卖家 ID，当前属性表的主键 |
| seller_zip_code_prefix | 卖家邮编的前五位，按字符串保存 |
| seller_city | 来源记录中的卖家城市 |
| seller_state | 来源记录中的卖家州缩写 |

卖家表一行一个卖家的属性记录，商品明细表一行一条订单商品明细。卖家在明细表中可出现多次，不按 seller_id 去重。卖家表没有订单数、销售金额或评分，这些需要从业务表计算。

本课不把卖家记录中的地区直接解释为每条商品的实际发货地点。

## 地区字段怎么处理

1. 使用 sellers_raw.copy() 创建工作副本。
2. 地区去首尾空白，城市统一小写、州统一大写。
3. 分开检查邮编五位数字格式、州两位大写字母格式、州代码成员和城市缺失。
4. 保留问题记录，先输出标记，不擅自补零或合并城市。

本批三个地区字段的格式规范变化数均为 0，上述四种核查标记也均为 0。州代码复用客户阶段保存在 docs/references/ibge_state_codes_v1.json 的参考快照，运行时不联网。

格式检查通过不等于地理对应关系已核实。城市标签相同但州不同，既可能存在同名，也可能是记录问题，后续结合地理表核查。
