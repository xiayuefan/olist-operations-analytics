# 商品阶段整理：商品属性、品类映射与销售明细

你已经在第十二份 Notebook 完成商品主键、品类翻译、数值属性、重量与体积，以及商品属性关联的检查。现在打开 notebooks/13_商品阶段整理.ipynb，独立复现这一阶段。第十二份 Notebook 保留你的课堂记录。

## 本课需要掌握什么

不是再增加一个分析指标，而是将已完成的步骤串成可重复运行的流程，并能解释输入、输出和表的粒度。

| 表 | 一行的含义 | 主键 |
| --- | --- | --- |
| 商品属性表 products_clean | 一个商品的属性记录 | product_id |
| 翻译映射 raw_translation | 一个葡萄牙语品类的英文名称 | product_category_name |
| 关联后销售明细 items_with_products | 一笔订单中的一条明细，附带商品属性 | order_id + order_item_id |

同一 product_id 在明细表中出现多次，可能对应不同订单，也可能对应同一订单的不同明细序号。它们应保留，不能按 product_id 直接去重。商品表没有销售价格；金额仍取明细表。

## 函数调用顺序

| 函数 | 输入 | 返回值 |
| --- | --- | --- |
| join_product_categories | 原始商品表、原始翻译表 | 一行一个商品的副本，新增英文品类和缺失原因标记 |
| check_product_numeric | 商品属性表 | 七个数值字段的检查表，不修改输入 |
| clean_product_attributes | 已关联翻译的商品表 | 完整商品副本，规范数值类型，新增重量、尺寸资格和体积 |
| clean_order_items | 原始商品明细表 | 前面课程的明细副本，含规范主键、整数分和核查标记 |
| join_items_products | 规范后的商品明细、商品属性表 | 一行一条销售明细，补充商品属性 |
| reconcile_product_totals | 关联前、后的销售明细 | 数量、商品金额及运费控制表；差额或主键异常时停止 |
| product_attribute_coverage | 商品属性表、关联后明细 | 各质量条件的商品数与销售明细数 |

函数实现位于 src/products_cleaning.py，金额继续复用 src/items_cleaning.py。

两个关联都使用 many_to_one：商品关联翻译时检查右侧品类键唯一，明细关联商品时检查右侧商品 ID 唯一。validate 检查关系，不替你去重。

## 缺失标记与计算资格

原始品类缺失 610 个商品，非空品类未翻译 13 个商品，两类都保留。未翻译品类为 portateis_cozinha_e_preparadores_de_alimentos（10 个商品）和 pc_gamer（3 个商品）。本阶段不自动补译、不据此删除商品或销售明细。

七个数值字段的非空值在当前数据中均为整数，转换为可空 Int64。保留原始列名中的 lenght 拼写；两个长度字段是字符数，不是商品名称或描述文本。解析失败、非有限值、小数、负数会停止核查，缺失值不会填零。

体积条件只要求三边非空且大于零。重量为零的 4 个商品，尺寸都完整，体积都是 22,500 cm³；它们不能用于正常重量统计，但可以保留尺寸乘积。这个乘积尚未验证为真实包装或计费体积，极端值也需要结合业务核查。

## 为什么同时统计商品数和销售明细数

| 质量条件 | 商品数 | 涉及销售明细数 |
| --- | ---: | ---: |
| 原始品类缺失 | 610 | 1,603 |
| 有品类但无翻译 | 13 | 24 |
| 重量不满足基础条件 | 6 | 26 |
| 体积不可计算 | 2 | 18 |

610 和 1,603 分母不同：前者统计商品，后者统计这些商品在原始销售明细中的出现次数。它们不相等并不表示丢行或放大金额。

这张表的各条件可能重叠，不能直接相加当作去重异常总量。商品 ID 匹配成功也不代表所有属性完整。

## 独立复现与输出

在项目目录打开终端：

```powershell
Set-Location 'D:\数据分析\olist-operations-analytics'
python .\src\07_clean_products.py
```

默认读取同级 archive 里的三张原始 CSV。换目录时使用 --data-dir 指定原始文件夹。

- data/processed/products_v1/products_clean_v1.csv：完整商品工作表。
- data/processed/products_v1/items_with_products_v1.csv：带商品属性的销售明细。
- data/processed/products_v1/category_translation_v1.csv：经验证的来源翻译映射，未补译。
- reports/products_v1/商品阶段报告_v1.md：本阶段解释和检查汇总。
- 同一报告目录：主键、数值、品类覆盖、属性缺失影响、金额控制表、核查清单、metrics 和来源哈希。

CSV 不保存类型。重新读取时明确 ID 字符串、七个属性和体积的 Int64、可空布尔和日期。flag_weight_zero 的缺失表示重量未知，不能填成“已知不为零”。Parquet 与统一类型恢复留到清洗交付阶段。
