## Q24 用同一批订单比较两个模型

1. **定义订单主品类。** 在每笔订单内，把同一品类的商品金额加总，取总金额最高的品类。金额并列时按原始品类名排序取第一项。比如品类 A 有 60 和 50 BRL 两条明细，品类 B 有 100 BRL 一条明细，A 的合计是 110 BRL，所以这笔订单的主品类是 A。
2. **保留每单一行。** 品类未知单列。主品类在样本中不足 50 笔订单的已知品类合并为一组，减少样本很少的类别。50 笔是本课采用的阈值。所有模型仍使用相同订单和相同低评分定义。
3. **对照最后两行。** `state_and_month` 包含客户州和下单月份，`state_month_and_category` 再加入主品类。`late_odds_ratio` 的单位是倍，`low_score_gap_pp` 是两个平均拟合概率相减，单位是百分点。

主品类把多品类订单归到一个类别。第三行描述同州、同月、主品类组相同条件下的统计关联。平均拟合概率的计算也保留每笔订单的州、月份和主品类，只切换延迟标记。

已核对三个模型都使用同样的 95,560 笔订单，每笔只出现一次。第三行的优势比和平均拟合概率差值已用另一种求解器复核。
