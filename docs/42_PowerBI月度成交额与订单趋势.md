# 第 50 课 Power BI 月度成交额与订单趋势

在「经营总览」用两张折线图展示成交额和已交付订单数随月份的变化。两张图使用相同的月份顺序，各自保留金额和笔数的刻度。

1. 日期范围设为 **2017-01-01 至 2018-08-31**，再用月份切片器上的橡皮擦清空 `YearMonth` 的选中项。这样折线图能显示整个分析窗口。
2. 在「可视化」中选**折线图**，把 `Calendar[YearMonth]` 拖到 **X 轴**，把度量值 `[商品成交额（BRL）]` 拖到 **Y 轴**。标题设为「月度商品成交额（BRL）」。[Microsoft Learn · 创建折线图](https://learn.microsoft.com/zh-cn/power-bi/visuals/power-bi-line-chart#创建折线图)
3. 再加一张折线图，X 轴仍用 `Calendar[YearMonth]`，Y 轴换成 `[已交付订单数]`，标题设为「月度已交付订单数」。如果图按度量值大小排序，在视觉对象右上角的 `…` 菜单中选择按 `YearMonth` 升序。`yyyy-MM` 的文本升序就是月份先后顺序。

把鼠标移到数据点上，读该月的数值。横轴可能只标部分月份，工具提示会显示数据点对应的月份。整段区间应包含 20 个月。

| 月份 | 商品成交额（BRL） | 已交付订单数 |
| --- | ---: | ---: |
| 2017-01 | 111,798.36 | 750 |
| 2017-10 | 648,247.65 | 4,478 |
| 2017-11 | 987,765.37 | 7,289 |
| 2018-08 | 838,576.64 | 6,351 |

对照值已从本地 Parquet 重算。两张折线图的显示和筛选效果在 Power BI Desktop 中核对。

## 我的理解

1. 从图中读出 2017 年 10 月和 11 月的成交额、已交付订单数。11 月比 10 月分别增加了多少 BRL 和多少笔订单？
2. 清空月份切片器后，为什么卡片显示整个窗口的成交额，而折线图上的每个点只显示一个月的成交额？它们用的是同一个度量值。
