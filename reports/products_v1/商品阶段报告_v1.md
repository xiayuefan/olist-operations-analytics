## 数值与体积

| product_weight_g | 2 | 0 | 0 | 0 | 0 | 4 |
| product_length_cm | 2 | 0 | 0 | 0 | 0 | 0 |
| product_height_cm | 2 | 0 | 0 | 0 | 0 | 0 |
| product_width_cm | 2 | 0 | 0 | 0 | 0 | 0 |

七个数值属性的非空值在本批数据中均为整数，使用可空 Int64；缺失保留未知，不填零。非空解析失败、非有限值、小数或负数会停止导出并要求核查。这里的整数限制是当前来源精度约定，不代表所有场景的尺寸、重量都必须为整数。

体积特征为记录的长×宽×高，三边非空且大于零才计算；重量资格单独判断。重量为零的商品仍可能有完整尺寸。该特征尚未验证为实际包装体积或计费体积。本批可计算体积的中位数为 6840.0 cm³，最大值为 296208 cm³；仅凭极端值不能判为错误并删除。

同一商品可能出现多条销售明细，所以两列不应相等。各质量条件可能重叠，不能将这些行的数量相加当成去重后的异常总数。商品 ID 全部匹配也不代表属性全部完整。
